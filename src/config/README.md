# `src/config`

Configuración del estudio (SPEC §6.1, FR-03). Es lo que se cambia para convertir la demo en el sitio de un estudio real, sin tocar componentes.

- `site.config.ts`: nombre del estudio, profesionales y matrículas, dirección, horarios, teléfono, WhatsApp, email público, redes y coordenadas. Tipado. En la demo, con datos **ficticios** (SPEC §11.4).

Se crea en la tarea **F1-07**. Ningún componente debe hardcodear estos datos.
